# latex_templates

这里保存以后从已复核项目的 `final.md` 生成 LaTeX/PDF 的模板说明。排版工程是派生层，
不得在其中直接修改译文；文字修订必须回到翻译工作区并重新经过相应审校。

建议每个正式作品使用独立 LaTeX 工程：

```text
work-slug/
  main.tex
  ch01.tex
  ch02.tex
  ...
```

编译临时文件不长期保存。
