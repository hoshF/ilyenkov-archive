# 跨章翻译决定索引

**这是索引，不是第二个权威源。** 每条决定的正本仍在它原本的位置（术语表条目、体例规范、
某章 `issues.md`）；本文件只负责让写 prompt 的人**在一个地方扫完**所有具有跨章效力的裁定。

## 为什么需要它

「的大写『逻辑』」这条行文规则在 ch013 判定后**已经写进术语表 `logic` 条目**，但仍在
ch002、ch003 回潮 5 处。可见决定"有记录"并不等于"到得了起草方手里"——记录散落在十几个
`issues.md`、术语表 notes 与错误清单三处，写 prompt 时无从逐一回想。本索引即为此设。

## 使用方式（硬规则）

写任何一章的任务 prompt 时，**逐行扫过下表**，把"须进 prompt"标为是的条目确认已写进该章
prompt（通则部分或本单元要点）。审计完一章后，若产生新的跨章裁定，**在此追加一行**。
