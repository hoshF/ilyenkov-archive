# 网站与仓库架构

## 定位

中文伊里因科夫是面向中文读者的研究与资料网站，也是中文伊里因科夫小组公开出版物和工作成果的
身份锚点。网站介绍伊里因科夫本人、思想与著作，连接国际研究、会议和交流，并积累可修订的公开文本
与资料。本仓库负责网站实现，私有研究仓库（下称 private）负责研究来源。

本文件说明栏目、布局与文件所有权。权限和字段契约见[发布说明](PUBLICATION.md)，数据转换见
[内容管线](CONTENT_PIPELINE.md)，生产发布见[部署说明](DEPLOYMENT.md)。

顶部目录依次为伊里因科夫、档案、术语库、研究、小组、书籍。刊头处于普通文档流，只用文字站名；图形字标
保留在 favicon 与分享图中，不进入页眉。首页可见站名承担
`h1`，其他页面在正文中提供内容或栏目 `h1`。子页面使用面包屑表达所属关系。

页脚分两行：近期动态、关注与联系、RSS 在第一行，站名与项目与权利在第二行；入口来自站点配置。
首页与小组页在相应上下文链接联系页，不把联系、RSS 或子页面提升为顶部内容栏目。

## 内容组织

首页采用单列导读：定位句、人物简介与相关链接组成开场导读，随后依次为文本、研究、
中文伊里因科夫小组和近期动态；正文栏目标题从“文本”开始。
首页 `/` 读取生成输入 `ilyenkov.summary`，人物页 `/ilyenkov/` 使用 `identity`、
`originalName`、`lifespan` 与完整 `introduction`。首页的小组范围说明来自 `site.json` 的 `group.summary`；
小组页使用同一配置中的三语名称，以“小组介绍”和“关注与联系”链接进入说明与联系方式。
研究摘要复用已公开记录；文本、小组通讯和动态从各自集合派生，不复制事实源。
派生顺序见[文章集合与首页派生](CONTENT_PIPELINE.md#文章集合与首页派生)，日期语义见[发布说明](PUBLICATION.md)。

研究栏目以 IFI 网络、研究者目录和 Readings 会议系列组织入口。研究者目录读取已发布人物，
展示原名、简介与详情链接。IFI、Readings 详情页使用居中正文列，页首包含面包屑与相邻研究入口，页内浏览使用可展开目录，
资料入口放在正文末。IFI 区分网络形成背景、专题研讨会与计划活动；计划状态读取已公开记录，不根据
当前日期推断是否举行。Readings 按会议开始年份所属的年代分组，保留早期计数与国际届次的区别。
会议日期置于辅助列，窄屏回到正文上方；资料来源可展开查看。活动日期用数字与点号表示，以短横线连接范围，同年或同月省略重复部分，保留资料能够确认的精度。
当前 Readings 栏目按公开身份选择系列，依赖及失败行为见[Readings 页面依赖](CONTENT_PIPELINE.md#readings-页面依赖)。
不建立单届会议详情页。研究者页共用研究同级导航与面包屑；学术入口置于辅助栏，窄屏移至正文之后。

研究者目录的介绍优先使用选定成稿的 `editorial.workDescription`，未选择成稿时使用基本 `summary`。
目录介绍的这一回退不产生正式工作说明，也不改变 `editorial` 的生成条件。详情页正式简介只使用
选定成稿的 `editorial.introduction`，缺省时不渲染该节；首页和详情描述复用基本摘要。研究者页展示本站已公开译文，保留档案顺序及完整合著署名；关联过程见
[研究者同步与本站译文](CONTENT_PIPELINE.md#研究者同步与本站译文)。

人物总页以介绍第一段开场，姓名作为段首 `h1`，原文名与生卒年随后，不另设页首。
外部资料卡片与介绍相邻，包含选定的外部入口、照片及署名；照片与卡片标题链接到选定条目，
署名单独展示。研究者照片与姓名、简介形成同一介绍区域，窄屏回到正文流；照片缺省时省略照片区域。
人物总页资料卡片照片与研究者介绍照片均按 3:4 从顶部裁切，像素尺寸、间距和响应式断点由样式定义，源图校验见
[研究者身份与公开字段](PUBLICATION.md#研究者身份与公开字段)。

小组页介绍身份与工作范围，联系和参与信息归联系页；小组通讯是经过编辑选择的长期公共记录。
updates 是简短公开变化记录，不承担开发日志。联系页依次呈现获取更新、联系、参与研究与整理，
只提供文本链接和 `mailto:`，没有表单。项目与权利页面向读者，开发流程留在项目文档。

书籍列表按 `category` 分组：`translation` 为不显示标题的默认书架，其他类别显示标题，
空分类不显示。同一 `collection` 聚为一组，组内顺序见[网站书籍成稿](CONTENT_PIPELINE.md#网站书籍成稿)。
书籍详情的标题、封面与书目、译者引言和版次记录沿同一正文列排列。桌面版次说明只占侧边余白，
不挤压正文；窄屏下隐藏这份辅助栏，正文版次记录仍可阅读。

术语库列表以中文主译为词条入口，同时显示原词、类别及作者或名称类型。列表支持关键词、类别、
作者与名称类型的组合筛选，查询条件保存在网址中；手机默认收起筛选区，收起时显示当前条件。
词条按表标识与 ID 生成独立详情页；不同作者的同名概念分别保留。详情展示其他中文形式、外文
词形及用法与译名说明，空字段省略；说明按纯文本呈现。无脚本时仍可从完整列表进入词条详情。

## 布局原则

布局按读者任务组织，区分浏览、连续阅读与多类成果导航。

### 三类页面布局

| 页面类型 | 主要任务 | 辅助栏 | 主内容 |
| --- | --- | --- | --- |
| 栏目页 | 浏览内容与入口 | 只有真实分类或索引才保留 | 栏目标题、入口、列表与记录；无辅助功能时单列居中 |
| 阅读型详情页 | 连续阅读 | 页内目录和必要阅读辅助，不推开正文 | 内容题名、元数据、正文、注释、来源与文末导航 |
| 结构型详情页 | 在多种成果或分区间浏览 | 可呈现真实内容类型、子入口和当前选择 | 当前内容；辅助栏本身有信息价值时不强求几何居中 |

标题与主要内容属于正文列，左栏不放文章主标题或长篇介绍。面包屑位于正文前；辅助索引仅
列真实结构和去向。普通栏目不预留空左栏，手机按页面任务把辅助内容放回文档流或隐藏。

档案分类栏承担筛选与索引，正文列居中。文章页采用适合连续阅读的字体与底色；窄屏隐藏刊头和面包屑，
侧栏页内目录改为题名与原题之后的折叠目录。两份目录互斥显示，断点由样式定义。

版心、字号、间距、断点和吸附偏移以 `src/styles/global.css` 为准。刊头位于普通文档流，页内目录与
分类栏按各自布局吸附；页面以标题、位置和间距表达层级。
内容链接带细下划线；刊名、主导航、面包屑、页内目录、档案分类与栏目子导航靠位置说明可点，不加下划线。
块引用只用左侧细线标出范围，不加底色。

伊里因科夫专题子页共用同级导航，并从既有阶段、年代或体裁、主题生成可展开的页内浏览入口。
生平按成稿阶段排列；年表按事件开始年份所属的年代分段；作品目录按体裁排列；交往按成稿主题排列。
日期、原题和资料来源使用辅助层级，年表与交往的来源可展开查看。

文章页目录依正文标题顺序排列，有注释区时列“注释”，译文末尾提供“原文信息”跳转；正文无小标题时仍保留
这些入口。折叠目录至少有两项才出现。注释号与注释条目是锚点目标：返回正文时注释号停在视口约三成处，
当前注释条目以左侧细线标出；选择减少动画时不做平滑滚动。
文章页输出静态 HTML，侧栏目录使用渐进增强脚本标记当前章节；折叠目录与注释往返使用原生
`details` 与锚点，没有脚本时照常可用。
RSS 的静态生成与订阅发现见[RSS 订阅](CONTENT_PIPELINE.md#rss-订阅)。

译文图片宽大于高时标为横图（`prose-image--landscape`），铺满正文行宽；其余标为竖图
（`prose-image--portrait`），统一宽度居中。图注用浅色小字居中，竖图图注不宽于图片；
图片与注释的标记和转换规则见[译文转换](CONTENT_PIPELINE.md#译文转换)。

## 文件所有权

| 位置 | 所有权与用途 |
| --- | --- |
| private 研究仓库 | canonical 人物、作品、事件、原文、译文、研究笔记、来源和权利证据 |
| private `web/publication.json` | 译文、研究、网站书籍、术语与分类的唯一发布选择入口；引用事实、文本、来源文件及选定的公开成稿 |
| private `web/editorial/` | IFI、Readings 的介绍与导语，研究者中文介绍与研究工作说明，年表与作品目录说明，生平分期与导引、交往主题与记录范围；不替代 canonical 事实记录 |
| `editorial/site.json` | 站点身份、顶部导航、页脚、小组三语名称、summary 与正式联系邮箱的单一配置源 |
| private `web/editorial/ilyenkov.json` | 人物总页短摘要、完整介绍、页面说明与子页入口名称和导语；人物事实引用 canonical records |
| private `web/editorial/books/` | 网站书籍元数据、版次与介绍；由 books 显式选择，经生成输入消费 |
| `editorial/group/` | 小组按期公共工作记录及其摘要、公开日期 |
| `editorial/updates.json` | 简短公开动态的单一事实源 |
| private `web/editorial/archive-taxonomy.json` | Archive 的公开编辑分类及逐篇指派，不是作者事实 |
| private `glossary/` | 术语词条的唯一手工维护源；按作者理论概念、通用学科术语、专名与体制词分表 |
| `scripts/` | 发布选择校验、同步、字段裁剪与输入生成 |
| `src/` | 页面、组件、布局、公开数据适配、Markdown 渲染与样式 |
| `tests/` | 权限边界、数据契约、页面结构和样式行为的回归检查；共享读取入口在 `tests/helpers/` |
| `docs/` | 架构、权限、数据流和部署的维护说明 |
| `public/` | 可直接公开的静态资产 |
| `.website-input/`、`dist/` | 生成输入与静态产物；忽略且不提交，不手工维护 |

private 成稿负责文字、阶段及主题顺序；public 负责路由映射、分组、记录排序和格式，
不以页面 ID 白名单或集合首末项推断生平。选定成稿的字段及缺省行为见
[公开编辑文字](PUBLICATION.md#公开编辑文字)，引用与摘要解析见
[生平与交往](CONTENT_PIPELINE.md#生平与交往)。

研究详情页的资料入口由 `ResourceLinks` 展示；页面负责选择公开资源及中文标签。
首页、Archive 与研究者页的公开文本条目共用 `TextRecord`，各模式保留自身的顺序和标题层级；
排序、人物关联及列表容器仍由调用页面负责。
