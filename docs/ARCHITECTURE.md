# 网站与仓库架构

## 定位

中文伊里因科夫不是 private 研究仓库的公开镜像，也不只是正文列表。它承担三项长期职责：

1. 面向中文读者系统介绍伊里因科夫本人、思想和著作；
2. 连接中文世界与国际伊里因科夫研究、会议、组织和交流；
3. 作为中文伊里因科夫小组全部公开出版物和项目成果的身份锚点。

## 信息架构

| 栏目 | 路由 | 职责 | 主要公开对象 |
| --- | --- | --- | --- |
| 伊里因科夫 | `/ilyenkov` | 人物、语境和阅读路径的导览 | 生平、年表、作品目录、交往与活动 |
| ├ 生平 | `/ilyenkov/life` | 已公开生平事实的阶段性入口 | 目前为 1924—1953 年生平坐标，以及服役、作品与国际活动阶段；不构成完整传记 |
| ├ 年表 | `/ilyenkov/timeline` | 已公开研究事实的统一时间坐标 | 目前混排生平、服役与黑格尔大会记录；不纳入作品发表节点 |
| ├ 作品目录 | `/ilyenkov/works` | 以作品为单位连接公开书目来源 | 首批为两部已确认著作、一篇早期理论论文与五篇战时写作；逐步补充原始版本与中文状态 |
| └ 交往与活动 | `/ilyenkov/circle` | 已公开活动资料的主题入口 | 目前为服役与国际黑格尔大会记录 |
| 档案 | `/archive` | 进入已获准在本站阅读的文本 | 公开译文与数字化文本；不展示内部研读状态 |
| 研究 | `/research` | 国际研究与交流地图 | IFI 研究网络、迈丹斯基阅读入口、Filorus 资料站点与伊里因科夫讨论会 |
| 小组 | `/group` | 中文伊里因科夫小组自身的公共档案 | 经选择公开的活动、会议、合作记录与小组署名文章 |
| 书籍 | `/books` | 统一维护成书的公开身份 | 封面、书名、版次、勘误、译者引言 |
| 关于 | `/about-us` | 说明小组、建站缘由与网站使用路径 | 网站缘起、工作范围与栏目导览 |
| 项目与权利 | `/about` | 解释边界和方法 | 来源、授权、技术与隐私原则 |

栏目页之间必须保持互相可达。全站可达性由顶栏和页脚这两处固定导航保证：顶栏是五个一级栏目的
入口，页脚只补顶栏够不到的部分（子页面、`/about`），两者不重复彼此已有的链接。正文内部的链接是
上下文相关的引用，不是为了凑数的固定出口——空栏目的“当前状态”段落仍然应该指向当前真正有内容
的地方，但这是内容层面的要求，不是每页必须凑够几条链接。网站结构测试会校验导航中每个
链接都对应一个真实页面。

首页不再重复一级栏目说明，而采用思想写作网站的结构：紧凑的站点身份、已公开文本和通往独立
“关于”页面的侧栏导引。完整文本列表集中在档案页，栏目页继续承担系统介绍和长期资料组织。

普通栏目页使用“栏目定位＋实际内容”的双栏结构；内容较长的 `/research` 在宽屏增加只服务于
当前页面的页内目录。页内目录不是跨栏目推荐，也不承担发布状态说明；在中等屏幕移到正文上方，在窄屏
与其余栏目一起回退为单栏。文章正文和书籍详情继续使用单一阅读栏。

## 两个仓库

```text
private 研究系统
  来源发现 · 原文 · 翻译 · 审校 · 权利证据 · 发布决定
                 │
                 │ translation/publication.json 选择 website_public
                 ▼
public 发布系统
  同步 articles · 编辑组织 · 页面 · 样式 · 静态构建 · 部署 · 出版记录
```

public 直接读取发布清单中指定的 `work.json` 和同目录 Markdown，不扫描未列入清单的研究内容。
1924—1953 年生平坐标由 private 的 `research/publication.json` 逐条选择；public 同步器只输出批准的中文标题与摘要、历史日期、可选地点和外部来源链接。首批来源限定为 1953 年自传的公开书目页与 Filorus 生平页；自传正文、档案文件、扫描件、摘录、冲突分析和本地路径均不输出。来源之间存在冲突时，公开数据只保留能够共同支持的最小事实，例如童年迁居莫斯科不附争议年份。
服役与黑格尔大会资料也由这份清单逐条选择；public 同步器只输出其中批准的中文摘要、
历史时期、地点／状态与外部来源链接。`/ilyenkov/timeline` 只在 public 中将这批已公开资料按历史日期混排；
它同时纳入获准的生平坐标，但不补写未选中的人生事件、不加入作品发表节点，也不把尚未覆盖的年代当作事实空白。private 若调整这些路径或字段，需要同步更新发布清单或本仓库的同步器。
作品目录同样由这份清单逐条选择：public 只读取选中的总录条目和选中的公开书目／原文来源，不输出正文、扫描件、内部身份证据或待复核作品。
伊里因科夫讨论会也由这份清单逐届选择：public 只读取选中的会议记录与其届次目录中的公开来源，输出届次、题名、历史日期、地点或线上形式和来源链接；不输出报告、照片、视频、统计、组织细节或内部判断。
IFI 研究网络和 symposium 同样逐项选择：public 只读取选定的组织记录、活动记录及对应届次来源，输出最小组织身份与活动定位；不读取成员、webinar、附件、资料目录、报告统计或内部判断。
研究者卡片同样使用逐项公开选择：public 只读取选定作者的最小身份、选定作品及对应外部来源，并验证其已公开的 archive 阅读入口；不读取作者履历、完整书目、机构、档案或未选作品。
外部资料站点也使用逐项公开选择：public 只输出批准的站点名称、简短中文定位和分类链接，并验证每个入口由站点来源页或明确选择的公开文件支持；不读取站点正文、附件、采集记录或未选资料。
`/group` 只记录中文伊里因科夫小组自身。当前 private 尚无完成公开选择的小组活动、会议或署名文章，
因此页面只提供栏目定位与准确空状态，不读取或重复汇总站内文章、书籍和研究资料。未来记录必须先在
private 中逐项批准公开；小组署名文章的正文仍以 `/archive` 为唯一阅读入口。
`/ilyenkov/life` 复用同一受控输出，将五条 1924—1953 年生平记录与已公开的服役、作品和国际活动资料组织为分期入口；它不读取自传正文，也不将 1954 年以后的空缺补写为完整传记。

## 仓库结构

```text
editorial/          站点身份与导航（site.json）
  books/            成书记录：frontmatter 出版元数据 + 正文为译者引言
docs/               架构、发布和部署规则
public/             可直接公开的静态资产
scripts/            private 译文与研究资料到构建输入的同步器
src/components/     展示组件
src/layouts/        站点框架
src/lib/            articles、Markdown 与公开数据适配
src/pages/          长期栏目、子页面和获准正文路由
src/styles/         全站视觉系统
tests/              发布边界与网站结构验证
.website-input/     忽略且禁止提交的网站构建输入
  articles/         由 website_public 译文生成的带 frontmatter 文章
dist/               静态构建结果；忽略
```

## 内容归属

公开网站自身的站点身份、导航以及栏目页面文案在 `editorial/` 与页面中维护。研究事实、
作品记录、译文正文和权利决定必须来自 private 的 `website_public` 选择。public Git 不保存生成的
译文正文，只保存同步、渲染和展示逻辑。
