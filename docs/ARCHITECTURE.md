# 网站与仓库架构

## 定位

中文伊里因科夫不是 private 研究仓库的公开镜像，也不只是正文列表。它承担三项长期职责：

1. 面向中文读者系统介绍伊里因科夫本人、思想和著作；
2. 连接中文世界与国际伊里因科夫研究、会议、组织和交流；
3. 作为中文伊里因科夫小组全部公开出版物和项目成果的身份锚点。

## 信息架构

| 栏目 | 路由 | 职责 |
| --- | --- | --- |
| 伊里因科夫 | `/ilyenkov` | 人物、语境和阅读路径的导览 |
| ├ 生平 | `/ilyenkov/life` | 已公开生平事实的阶段性入口，不构成完整传记 |
| ├ 年表 | `/ilyenkov/timeline` | 已公开研究事实的统一时间坐标 |
| ├ 作品目录 | `/ilyenkov/works` | 以作品为单位连接公开书目来源 |
| └ 交往与活动 | `/ilyenkov/circle` | 已公开活动资料的主题入口 |
| 档案 | `/archive` | 进入已获准在本站阅读的文本 |
| 研究 | `/research` | 国际研究与交流地图 |
| 小组 | `/group` | 小组与网站的说明，以及小组自身的公共记录 |
| 书籍 | `/books` | 统一维护成书的公开身份 |
| 项目与权利 | `/about` | 解释边界和方法 |

栏目页之间保持互相可达。全站唯一的固定导航是顶栏，入口为五个一级栏目；子页面由所属栏目页
链接，`/about` 由 `/group` 链接。正文内部的链接是上下文相关的引用。网站结构测试会校验导航中
每个链接都对应一个真实页面。

版式上只有三条长期约定：栏目页是“栏目定位在左、内容在右”的双栏；有明确父子关系的页面在正文前
显示位置导航，一级栏目不显示；文章正文保持单一阅读栏。具体的间距、断点与组件样式以
`src/styles/global.css` 和结构测试为准。

页面是静态 HTML，不做 hydration。全站只有一段客户端脚本：译文页把页内目录当前所在的章节标成
`aria-current="location"`。它是渐进增强，只随 `/archive/<id>` 输出；没有它时目录仍然是一组可用的
锚点。再要加脚本，先确认同一件事没法用 HTML 或 CSS 做到。

## 两个仓库

```text
private 研究系统
  来源发现 · 原文 · 翻译 · 审校 · 权利证据 · 发布决定
                 │
                 │ publication.json 逐项选择 website_public
                 ▼
public 发布系统
  同步输入 · 编辑组织 · 页面 · 样式 · 静态构建 · 部署 · 出版记录
```

public 只读取发布清单中逐项指定的记录、字段和来源，规则见[发布说明](PUBLICATION.md)。private
调整路径或字段时，需要同步更新发布清单或本仓库的同步器。

## 仓库结构

```text
editorial/          站点身份与导航（site.json）
  books/            成书记录：frontmatter 出版元数据 + 正文为译者引言
docs/               架构、发布和部署规则
public/             可直接公开的静态资产
scripts/            private 译文与研究资料到构建输入的同步器
  lib/              两个同步器共用的路径、校验与写盘外壳
  lib/research-sync/  研究资料的选择、来源解析与公开字段裁剪
src/components/     展示组件
src/layouts/        站点框架
src/lib/            articles、Markdown 与公开数据适配
src/pages/          长期栏目、子页面和获准正文路由
src/styles/         全站视觉系统
tests/              发布边界、网站结构、Markdown 渲染与样式表验证
  helpers/          页面源码、样式表与发布清单的读取入口
.website-input/     忽略且禁止提交的网站构建输入
dist/               静态构建结果；忽略
```

## 内容归属

站点身份、导航与栏目页面文案在 `editorial/` 与页面中维护。研究事实、作品记录、译文正文和权利
决定来自 private 的 `website_public` 选择；public Git 只保存同步、渲染和展示逻辑。
