# 网站与仓库架构

## 定位

中文伊里因科夫不是 private 研究仓库的公开镜像，也不只是正文列表。它承担三项长期职责：

1. 面向中文读者系统介绍伊里因科夫本人、思想和著作；
2. 连接中文世界与国际伊里因科夫研究、会议、组织和交流；
3. 作为中文伊里因科夫小组全部公开出版物和项目成果的身份锚点。

## 信息架构

| 栏目 | 职责 | 主要公开对象 |
| --- | --- | --- |
| 伊里因科夫 | 人物、问题、语境和阅读路径 | 导论、年表、专题入口 |
| 档案 | 按日期进入公开文本，并连接作品、版本和访问状态 | 公开全文、作品目录、研读状态 |
| 研究 | 国际研究与交流地图 | 研究者、著作、会议、组织、访谈 |
| 小组 | 中文伊里因科夫小组的公共记录 | 活动、产出、讨论记录、参与方式 |
| 出版 | 统一维护正式成果 | 书籍、专题、版本、勘误、发行说明 |
| 项目与权利 | 解释边界和方法 | 来源、授权、技术与隐私原则 |

首页不再重复一级栏目说明，而采用思想写作网站的结构：居中的站点身份、近期公开文本和侧栏导引。
完整文本列表集中在档案页，栏目页继续承担系统介绍和长期资料组织。

## 两个仓库

```text
private 研究系统
  来源发现 · 原文 · 翻译 · 审校 · 权利证据 · 发布决定
                 │
                 │ translation/publication.json 选择 website_public
                 ▼
public 发布系统
  同步 articles · 编辑组织 · 页面 · 样式 · 静态构建 · 部署 · 出版记录
```

public 直接读取发布清单中指定的 `work.json` 和同目录 Markdown，不扫描未列入清单的研究内容。
private 若调整这些路径或字段，需要同步更新发布清单或本仓库的同步器。

## 仓库结构

```text
editorial/          站点身份与导航（site.json）
docs/               架构、发布和部署规则
public/             可直接公开的静态资产
scripts/            private 译文到 articles 的同步器
src/components/     展示组件
src/layouts/        站点框架
src/lib/            articles、Markdown 与公开数据适配
src/pages/          长期栏目和获准正文路由
src/styles/         全站视觉系统
tests/              发布边界与网站结构验证
.website-input/     忽略且禁止提交的网站构建输入
  articles/         由 website_public 译文生成的带 frontmatter 文章
dist/               静态构建结果；忽略
```

## 内容归属

公开网站自身的站点身份、导航以及栏目页面文案在 `editorial/` 与页面中维护。研究事实、
作品记录、译文正文和权利决定必须来自 private 的 `website_public` 选择。public Git 不保存生成的
译文正文，只保存同步、渲染和展示逻辑。
