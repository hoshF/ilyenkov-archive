# 《伊里因科夫的哲学、文本与研究》写作计划

本目录持续撰写和修订《伊里因科夫的哲学、文本与研究：一份中文学术导论》——一篇以原始文献、文本发生史、档案材料和研究史为基础的中文学术综述，系统介绍埃瓦尔德·瓦西里耶维奇·伊里因科夫的生平、哲学、学术关系、文本保存及国际研究。

## 定位

**写给人读，不是写给 agent 读的。** 本文不是仓库的事实依据，也不是任何流程的输入：agent 不得引它作为版本、年代、术语或文本身份的根据——那些的正本是语料 Markdown、`work_manifest.json`、`metadata/` 与各作者的 glossary。它是一篇文章，价值在论述本身。相应地，`gbrain.yml` 的 `db_tracked` 不含 `book/`，本目录不进入 GBrain 索引；front matter 里 `llm_wiki_eligible` 与 `gbrain_source` 均已声明为否。

**可以脱离项目存在。** 它不依赖本仓库的目录结构、脚本或流程即可阅读与发表；引用材料时给出可独立追溯的初刊或正式版本信息，而不是仓库路径。

**随项目与全球伊里因科夫研究的进展不断更新。** 新的文集卷次、档案出版、研究成果出现时，按既有章节增订。因此它是**项目发展的一部分而非一次性产物**，自 2026-07-30 起纳入 Git：正文与本说明的每次增订都提交，改动史即研究进展的记录。此前本目录曾被 `book/.gitignore` 整体排除，那条排除已取消。

版权与出版依 [`GOVERNANCE.md`](../../GOVERNANCE.md)：项目原创文稿用 CC BY-SA 4.0；若要正式发表，署名与出版方式同样只能以项目名义。

## 写作目标

文章以伊里因科夫关于思维形式的研究为中心，说明辩证逻辑、抽象与具体、观念的东西、对象性活动、思维着的身体、人格、教育与自由之间的理论联系。生平叙述服务于思想形成史和学术制度史，不以轶事、受难叙事或单一政治解释代替哲学分析。

文章保持学术综述性质：

1. 以连续论述组织材料，不写成作品摘要、资料清单或搜索记录。
2. 每一理论问题同时交代原文依据、论争背景、概念结构和后续解释。
3. 将伊里因科夫的作者原文与档案、回忆录、身后编辑本及二手研究明确区分。
4. 对研究者的解释和批评注明归属，不将其改写成伊里因科夫本人的观点。
5. 随着新文集卷次、档案出版和研究成果出现，按既有章节增订，而不以动态进度信息改变文章的基本结构。

## 材料层级

正文按以下次序使用材料：

1. 伊里因科夫生前定稿并发表的著作、论文和百科条目；
2. 有明确版本说明的未刊手稿、书信、会议记录和身后编辑文本；
3. 正式出版的家庭档案、机构档案及文集；
4. 同时代人的回忆录和口述见证；
5. 迈丹斯基、巴克赫斯特、马列耶夫等研究者的研究；
6. 文本网站、学术组织网站和数字导航资源。

回忆录主要用于重建交往史、生活史、教学实践和接受史。涉及政治压力、家庭生活、疾病与死亡的材料，应标明回忆者身份和叙述时间；无法互证的细节以“某人回忆”的形式表述。网络页面承担检索和导航功能时，正文引用仍尽可能追溯初刊或正式版本。

## 术语与专名

术语以 `ilyenkov_markdown/metadata/glossary.json` 为首要依据，并结合项目中相关作者的正式术语记录。正文固定使用“观念的东西”“一般”“普遍物”“具体的普遍物”“对象性活动”“共同—分担活动”“思维着的身体”和“活动论进路”等审定译法。

人物首次出现时给出中文全名以及俄文姓名或通行拉丁转写。未能核实完整姓名时保留原文首字母和姓氏，不根据转写猜测。尤里·尼古拉耶维奇·达维多夫与瓦西里·瓦西里耶维奇·达维多夫等同名或近名人物必须分别核对。

## 修订方法

每次增订以完整的论证单元为对象：

1. 确认所讨论材料的文本身份、版本和初刊信息；
2. 对照术语表和作品登记；
3. 在正文中完成论点、材料与研究争议的整合；
4. 使用语义稳定的 Markdown 脚注标识补充引注；
5. 同步更新文末相应类别的参考文献；
6. 检查重复论述、章节过渡、专名、年份及版本关系。

正文不使用未经人工核验的 OCR 草稿、AI 摘要或来源不明的网络转录作为引文依据，也不公开链接未经授权的全文下载。网络可访问性不等于转载许可。
