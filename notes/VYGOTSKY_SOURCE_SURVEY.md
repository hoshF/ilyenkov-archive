# L. S. Vygotsky Text Source Survey

本文记录维果茨基文本搜集的第一轮索引调查。它不是 corpus 录入清单，也不说明任何全文已经
通过版权、版本或人工校勘审核。PDF、DjVu、馆内电子阅览、自动 OCR、商业再版和网页转录
必须分开处理。

## Initial Processing Order

1. 以 PsyJournals 作者页建立 `works_master` 草表，先区分：作者原文、编辑/序言、合著、
   讲稿、手稿、档案首发、后世编选、翻译。
2. 用 НЭБ、GNPBU、RSL 记录核对版本事实：题名、出版地、出版社、年份、页数、责任者、
   馆藏来源和访问限制。
3. 对六卷本只保存扫描来源线索；如以后下载扫描，必须进入注册的 `source_scans/` 和 manifest，
   且不得读取 OCR 文本层作为正文。
4. 对 `psychlib.ru`、MIA、RoyalLib、Pedlib、Koob、Klex 的网页文本逐项做版本比对；
   只有可解释来源、结构完整、权利状态可记录的文本才进入 Markdown 候选。
5. Google Scholar、Academia、Springer、WorldCat、Open Library 主要用于版本发现、
   引文追踪和翻译层索引，不作为俄文 corpus 正文依据。
