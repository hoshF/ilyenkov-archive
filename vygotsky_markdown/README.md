# Lev Vygotsky Russian Source Text Archive

本 collection 保存列夫·维果茨基（Лев Семенович Выготский）的源语言文本线索、书目、
扫描件、出处元数据和少量已标明版本关系的网页文本见证。当前阶段只采集俄文原文来源；译本
和二级研究只作为索引线索，不下载为扫描库内容。

与项目的关系：文化历史心理学、活动理论与伊里因科夫相关思想语境。

目录使用标准 collection 布局。可检索正文、未处理扫描、书目和元数据必须分离；未处理扫描
不得 OCR，不得读取 PDF/DjVu 文本层，也不得进入 GBrain 正文索引。后出期刊重刊或片段文本
只能作为 `text_witness`，不得直接标为 `author_original`。
